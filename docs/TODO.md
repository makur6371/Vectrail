## [Pending] 插件开发任务：DJI 无线素材导入（`dji-wireless-import`）

- **状态**：待开始（Backlog）
- **登记日期**：2026-11-26
- **插件标识**：`dji-wireless-import`

### 一、开发目标

为当前 Windows 自动剪辑软件开发一个独立的 DJI 相机无线连接与素材导入插件，实现类似 DJI Mimo 的无线素材传输能力。

用户无需通过手机中转、拔插存储卡或连接数据线，即可在剪辑软件内连接大疆相机、浏览素材、下载原始视频和图片，并将其直接导入剪辑素材库。

### 三、开源项目评估与选型

对每个候选项目进行比较，按照以下权重综合评估：

- Windows 平台兼容性：20%
- 连接及传输稳定性：20%
- 与当前软件技术栈的适配成本：20%
- 相机型号覆盖范围：15%
- 原始素材传输速度：10%
- 代码质量及维护活跃度：10%
- 依赖体积及资源占用：5%

开源许可证及商业使用合规性作为前置准入条件，不符合要求的项目直接排除。

重点确认：
- 是否真正支持电脑直连相机，而非依赖手机。
- 是否支持蓝牙发现、配对与 Wi-Fi 连接。
- 是否能够获取完整媒体文件列表。
- 是否支持原始文件下载，而非仅下载压缩预览。
- 是否支持大文件、批量下载和断点续传。
- 是否需要额外运行环境、驱动或系统权限。
- 是否能够提取底层通信模块，而非嵌入完整第三方软件。
- 是否支持 Pocket、Action、Nano 等系列设备。

不以 GitHub Star 数量作为唯一判断标准。允许选择一个项目作为核心实现，也允许组合多个项目的成熟模块。优先复用经过验证的代码，不重复造轮子。

### 四、插件架构要求

首先分析当前 Vectrail 项目的技术栈、目录结构、素材管理机制、任务调度机制及已有插件架构。遵循现有架构，不进行无关重构。

将 DJI 相关能力封装为独立插件，建议插件标识为 `dji-wireless-import`。

插件内部应将以下能力解耦：
1. 设备发现与识别。
2. 蓝牙配对与身份验证。
3. Wi-Fi 连接管理。
4. DJI 通信协议适配。
5. 远程媒体文件索引。
6. 下载任务队列。
7. 本地文件校验。
8. 剪辑软件素材库导入。

禁止将 DJI 专有通信逻辑大量耦合进主程序。

插件应支持独立启用、禁用、更新与故障隔离。插件异常不得导致主程序崩溃或影响正常剪辑功能。

若当前项目尚无插件系统，采用最小侵入式模块化方案实现，不要为了单个插件重新设计整套软件架构。

如果主程序使用 Rust、TypeScript 或其他技术栈，不强制将所有成熟开源实现重新编写。可根据性能、打包体积及维护成本，选择原生模块、Sidecar 或其他合理的跨语言集成方式。

### 五、功能开发范围

#### P0：核心功能，优先完成
- 搜索附近支持的 DJI 相机。
- 识别设备名称、型号及连接状态。
- 完成必要的配对和授权流程。
- 建立相机无线连接。
- 获取照片和视频文件列表。
- 显示文件名称、大小、拍摄时间等可获取信息。
- 支持单选、多选和批量下载。
- 显示实时传输速度、进度和预计剩余时间。
- 支持取消下载、失败重试。
- 保留原始文件质量，不进行二次压缩。
- 下载完成后直接导入 Vectrail 素材库。
- 处理断开连接、相机休眠、网络异常等情况。

#### P1：体验优化
- 缩略图与视频预览。
- 已连接设备记忆。
- 自动重连。
- 断点续传（若协议支持）。
- 重复素材识别。
- 按拍摄日期和文件类型筛选。
- 批量下载队列管理。
- 下载目录设置。
- 连接前后的网络状态恢复。

#### P2：差异化功能
- 自动识别相机新增素材。
- 新素材增量同步。
- 下载完成后自动触发剪辑工作流。
- 自动生成代理素材。
- 自动进行素材分析、分类及镜头识别。

当前优先解决连接、传输与素材导入，不要过早扩展远程拍摄、云台控制等与自动剪辑无关的功能。

### 六、UI 与交互设计

在现有素材导入区域增加「从 DJI 相机导入」入口。插件界面应与 Vectrail 现有设计语言保持一致，不直接照搬第三方客户端界面。

推荐交互流程：`发现相机 → 连接相机 → 浏览素材 → 选择素材 → 下载并导入 → 开始剪辑`

重点保证：
- 不要求普通用户手动输入 IP 地址、端口或执行命令。
- 连接状态清晰可见。
- 下载过程不阻塞主界面。
- 错误信息使用用户能够理解的语言。
- 支持在后台传输素材的同时继续剪辑本地已有素材。

### 七、性能与稳定性

- 优先使用相机支持的高速 Wi-Fi 通信方式。
- 大文件采用流式写盘，禁止将完整视频加载到内存后再保存。
- 合理控制并发下载数量，避免造成相机过载。
- 下载中使用临时文件，校验完成后再转为正式文件。
- 避免重复下载和不必要的文件复制。
- 保证下载文件的完整性。
- 不擅自删除或修改相机中的原始素材。
- 不将素材上传至第三方服务器。
- 不硬编码设备密码、型号、地址及未经验证的协议参数。
- 特别关注 Windows 单无线网卡连接相机热点后可能出现的互联网连接中断问题，研究双网卡、有线网络并存及路由管理等可行方案，不承诺硬件本身无法实现的网络并行能力。
